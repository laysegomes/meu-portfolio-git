## 🚀 Como Visualizar o Portfólio Web no Localhost

Este repositório contém uma aplicação web responsiva (`index.html`, `styles.css`, `script.js`). Para visualizar localmente em seu navegador:

1. Abra o terminal na raiz deste projeto:
   ```bash
   cd /Users/laysegomes/Documents/projetos/meu-portfolio-git
   ```

2. Inicie o servidor HTTP local nativo do Python:
   ```bash
   python3 -m http.server 8000
   ```

3. Acesse no seu navegador:
   👉 **`http://localhost:8000`**
